# 🧮 Advanced Command Line Calculator (Python)

A feature-rich command line calculator built using Python.  
This project performs basic as well as advanced mathematical operations with proper error handling and a continuous user interface loop.

---

## 🚀 Features

✔ Addition  
✔ Subtraction  
✔ Multiplication  
✔ Division (with divide-by-zero handling)  
✔ Power (Exponentiation)  
✔ Modulus  
✔ Floor Division  
✔ Square Root  
✔ Percentage Calculation  
✔ Continuous execution until user exits  
✔ Input validation & error handling  

---

## 🛠 Technologies Used

- Python 3
- math module (for square root)
